# otw-exclusive design reference

Static HTML mockups in Design-canvas `.dc.html` format. Open them in a browser for markup/layout reference only; they are not production code. Owner-approved 20-10-26.

Artboards:

- `Main.dc.html`: homepage
- `Exclusive-page.dc.html`: `/exclusive`
- `Article.dc.html`: article page + Read next
- `Editorial.dc.html`: Editorial Standards
- `Chip-states.dc.html`: chip spec sheet
- `Mobile-home.dc.html`
- `Mobile-menu.dc.html`
- `canvas.json`: canvas layout

Notes:

- The live canvas is a private claude.ai artifact owned by the repo owner.
- Sample headlines come from the repo's demo fixtures in `apps/web/src/lib/data.ts`; which stories carry the chip is illustrative.
- Nav icons, cover art and the Brief band are simplified in the mockup; implementation keeps the real components.
